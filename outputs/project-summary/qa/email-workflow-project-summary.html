Email Workflow Platform

Project objectives and progress summary

Prepared: 2026-05-01 | Scope: repository summary, current workspace state, and recent run artifacts

Executive summary

The project has moved from a single email automation idea into a reusable platform for configurable, LLM-assisted email workflows. It now has a working engine, CLI, FastAPI admin UI, reusable providers/renderers, documented workflows, and concrete implementations for Citizen Brief, Weekend Weather + Surf, and Job Alert Digest.

Original Objectives

Create a durable home for multiple recurring email workflows instead of one-off scripts.

Treat workflows, prompts, configuration, templates, and documentation as first-class assets.

Make workflows easy to add, inspect, test, and evolve over time.

Use Gmail as a primary source where Alan's existing inbox and labels already contain useful signals.

Support LLM-driven synthesis while keeping provider details configurable.

Render polished HTML and plain-text email outputs, with optional Gmail delivery.

Workflow Progress

Citizen Brief is the reference workflow and demonstrates the platform's core gather, synthesize, render, and deliver pattern.

Weekend Weather + Surf is configured for Trigg Beach and has run artifacts with forecast, summary, HTML, text, and result outputs.

Job Alert Digest has been added as a first-class workflow that gathers Gmail job alerts, extracts opportunities, scores fit against Alan's profile, and renders ranked output.

Planned workflow documents exist for standalone surf and weather reports, keeping future expansion aligned with the shared engine.

Workflow request drafts now capture future workflow ideas before implementation, including economy sensemaking and Perth events.

Recent Changes Visible In The Workspace

HTML renderer improvements support reusable digest rendering and job-oriented output.

Tests have been added or updated for webapp behavior and the Job Alert Digest workflow path.

Validation And Evidence

Project includes pytest coverage for registry, runner, webapp, and workflow implementations.

Run artifacts exist for Weekend Weather + Surf and Job Alert Digest, including rendered HTML/text email outputs.

The package is configured with Python 3.11+, FastAPI, Jinja2, Pydantic, Click, Rich, httpx, pytest, Ruff, and MyPy.

Gmail access depends on the authenticated gog CLI; LLM use currently defaults to DeepSeek through an OpenAI-compatible provider.

Next Recommended Priorities
